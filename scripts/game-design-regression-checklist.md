# 游戏设计回归清单

## 目标闭环
- 完成一局任意游戏后，首页总星数会增加。
- 完成一局任意游戏后，成就数量可在满足条件时增长。
- 重启应用后，总星数与成就数量保持不回退。

## 反馈一致性
- 游戏内结果弹窗展示“本局结果”。
- 游戏顶部星数展示“长期累计”或明确标注语义，不与本局结果混淆。
- 成就页“已获得 X / 总数”中的总数与成就定义条数一致。

## 难度曲线
- 数数玩法随关卡提升，目标数字区间逐步提升。
- 接龙玩法随关卡提升，数字数量逐步增加。
- 配对玩法随关卡提升，配对对数逐步增加。
- 加法玩法随关卡提升，出题范围逐步增加。

## 成就规则
- `first_game` 可在首次完成游戏后解锁。
- `perfect_score` 的判定阈值与游戏内“满分”语义一致。
- 成就解锁条件来自统一统计口径，不依赖手工更新。

## 自动化命令
- `npm run check:ux`
- `npm run check:game-design`
