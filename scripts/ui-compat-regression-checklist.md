# UI 兼容性回归清单（手机/平板 + 横屏/竖屏）

## 覆盖设备
- 手机竖屏（小屏）
- 手机横屏
- 平板竖屏
- 平板横屏

## 核心流程
- 首页可正常进入游戏与成就页，无遮挡、无错位。
- 进入配对页后，顶部与内容不被刘海/状态栏遮挡。
- 游戏完成弹窗完整可见，按钮可点击。
- 返回链路正常：游戏 -> 首页 -> 成就 -> 首页。

## 布局检查
- 底部 Tab 在不同设备和方向下不遮挡内容，底部留白自然。
- 成就页徽章区域在窄屏下不溢出，文本不重叠。
- Profile 编辑弹窗在键盘弹出后输入框和按钮仍可操作。
- 数数/接龙/加法页面在横屏下无关键元素被裁切。

## 可访问性检查
- 返回按钮有可读名称。
- 首页游戏卡、成就入口可被读屏识别。
- 完成弹窗按钮可被读屏识别并可触达。

## 自动化检查命令
- `npm run check:ux`
- `npm run check:quality`
